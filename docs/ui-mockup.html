Regions

1
Menu bar

File / Edit / Search / View / Tools / Help, plus theme toggle and an offline-ready indicator (PWA install state).

2
Tab strip

Notepad++-style tabs, one document each. Green dot marks unsaved-to-file changes; every tab is always autosaved to IndexedDB. Language inferred from extension.

3
Editor (CodeMirror 6)

Line numbers, syntax highlighting, active-line highlight, search/replace, multi-cursor. All transforms apply to the selection, or the whole document when nothing is selected.

4
Live preview pane

Toggleable split view rendering Markdown with Mermaid and PlantUML fenced code blocks as diagrams. Scroll-synced with the editor. Hidden by default for non-Markdown tabs.

5
Tools menu

Every tool from the registry: encoding (Base64, URL, HTML entities), JSON, XML, text utilities, preview toggles, and file compare. All keyboard-accessible.

6
Status bar

Cursor position, character/word count, language, encoding — and autosave status, so users trust that nothing is ever lost.

Pick two open tabs — or a tab and a file from disk — and OpenPad renders a side-by-side diff (@codemirror/merge), the Notepad++ Compare plugin experience.

Diagram & markup support
  • Markdownworks offline Rendered locally (markdown-it) and sanitized (DOMPurify) before display.
  • Mermaidworks offline Rendered locally by the mermaid library, lazy-loaded so it never slows down plain editing.
  • PlantUMLneeds network PlantUML requires Java, so diagrams render via a PlantUML server (public by default, URL configurable for self-hosting). Offline, the preview shows the source with a clear "reconnect to render" notice.
